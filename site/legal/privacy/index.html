Privacy Policy

The Vibrix website is intentionally simple. The project does not run its own account system, advertising network, analytics platform, mailing list, payment system or tracking database on this site.

What the Vibrix site collects

The site's own HTML and JavaScript do not intentionally submit personal information to a Vibrix-operated backend. There is no Vibrix backend behind this GitHub Pages site.

GitHub Pages hosting

The website is hosted by GitHub Pages. GitHub states that visitors' IP addresses are logged and stored for security purposes. GitHub may process service and website usage information under its own privacy statement. That processing is performed by GitHub as the hosting provider, not by a Vibrix-operated server.

Live GitHub repository activity

The homepage requests public repository metadata and recent public repository events from the GitHub API in your browser. This is used to display public stars, forks, issue/PR counts, last-push information and public activity. Requests are made directly to GitHub and are subject to GitHub's privacy practices.

Fonts

The site's stylesheet currently requests DM Mono and Inter through Google Fonts. Your browser may therefore connect to Google's font infrastructure to obtain those resources. No Vibrix account identifier is sent by the site. A future privacy-hardening change may replace remote fonts with local/system fonts.

Cookies and local storage

Vibrix's own site code does not currently set cookies or use browser local storage for tracking. Hosting or third-party resources may process requests under their own policies.

Public GitHub information

The website may display public GitHub contributor names, handles and public repository activity. This information originates from the public Vibrix repository and GitHub's public APIs.

Children

The site is technical project documentation and is not designed to collect personal information from children. Do not submit sensitive personal information through public project channels.

Your choices

You can block third-party resources using browser privacy controls. You can also browse the source repository directly instead of using the project website. Requests concerning data processed by GitHub should be directed to GitHub under its privacy procedures.

Changes

This policy will be updated if Vibrix adds analytics, accounts, forms, downloads requiring telemetry, package services, or other features that materially change data processing.

Contact

For website/privacy questions specific to Vibrix, use an appropriate public repository issue unless the matter contains private or security-sensitive information. For GitHub-hosted data, use GitHub's privacy contact mechanisms.
