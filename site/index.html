01 / THE IDEA

An OS that goes
where you go.

The goal is one removable system drive carrying root, applications, settings and your home directory. Persistence is part of the architecture, not an afterthought.

Future compatible machines will rediscover the hardware at boot. Native USB storage and persistent root are still engineering milestones, not features available today.

08 / BUILD PHILOSOPHY

Independent.
Not isolated.

Agents must research primary specifications and upstream libraries, compare reasonable approaches, document provenance and licenses, and test actual target compatibility. Crates.io packages, reviewed Git revisions and properly licensed vendored crates are welcome.

CI checks known advisories, licenses, sources, lockfiles and features. It is not proof that every dependency is safe or that all host software was audited. Read the admission paths and coverage limits.
