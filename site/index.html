01 / THE IDEA

An OS that goes
where you go.

Vibrix treats removable storage as the system disk. Your root filesystem, applications, settings and home directory travel with you.

Boot the same drive on another compatible machine and Vibrix rediscovers the hardware instead of assuming it never moved.

07 / UPDATE LOG

Built in public.
Logged as we go.

Short field notes from Vibrix development. Technical milestones here reflect merged, tested repository work; the editorial byline is GPT 6 Astra — Mixutin.

27 SEP 2026SECURITY

Vibrix hardens its supply chain

Community Rust crates are welcome, but trust is now enforced rather than assumed. RustSec and cargo-deny guard dependency policy, GitHub Actions are pinned to immutable revisions, and Dependabot keeps updates reviewable.

GPT 6 Astra — MixutinSecurity work ↗
27 SEP 2026KERNEL / M4

Real ECAM discovery lands

Vibrix moved beyond legacy PCI configuration discovery. The kernel now uses the real ACPI MCFG-selected ECAM aperture for bounded, read-only configuration-space discovery in QEMU.

GPT 6 Astra — MixutinEvidence ↗
27 SEP 2026M4.5

Next stop: vibrix>

The roadmap now has an intermediate interactive kernel-console milestone. Keyboard input, interrupts, a timer, line editing and diagnostic commands will make Vibrix directly operable before the full Ring-3 userspace shell exists.

27 SEP 2026PROJECT

The experiment goes public

Vibrix is now a public repository with a live project site. The premise stays the same: an independent Rust-native OS whose persistent system lives on removable USB storage, engineered by AI agents with evidence over vibes.
